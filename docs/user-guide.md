# 使用指南

## 开始

完整解压应用目录后运行 `AnySidebarWindows.exe`。首次打开侧边栏，在设置中保存自己的 DeepSeek API Key。未填 Key 时发送会先显示提示，确认后定位设置，问题和引用保留。

点击桌面入口展开/收起；左上角按钮也可收起，三横线打开会话抽屉。右键入口或托盘可读屏、打开设置、隐藏入口或退出。隐藏入口后从托盘恢复。

收起继续生成，退出会先保存输入并停止请求。异常重开标记中断，不自动再次调用模型。

## 划词和图片

先在设置确认采集说明，再开启自动划词。默认仅最新引用，新选文替换旧选文；明确在来源取消选中时移除该引用。进入侧栏输入框打字仍保留。也可在设置切换累积，手动逐条移除。

划词只读取支持辅助功能选区的阅读区域，密码与可编辑输入排除。不支持时可框选截图，不自动模拟复制或扫描剪贴板。

Ctrl+Alt+A 默认框选区域，拖动后松开完成；Esc或再次按快捷键取消。读屏方式菜单也支持选择窗口，只取得当前可见内容，不承诺被遮挡或受保护窗口的隐藏内容。

截图先进入草稿，可以预览和删除，不会自动上传。每次最多9张、每张10MiB，加历史最多16图块，整个请求最多24MiB。超限给出提示，不偷偷删图。仅图片也能发送，默认解读可见内容。

## 会话与回答

会话由你手动新建、切换、重命名和删除。一个任务可讨论多份资料，切文件不换会话。截图和请求属于启动动作时的原会话，后台回答不会串入新会话。

Enter发送、Shift+Enter换行，输入法选字不会误发送。推荐问题点击直接发送；模型和思考强度在输入区切换。图像资料（包括历史）与文字模型不兼容时，会保留草稿并提示。

AI回答可划选引用，独立保留一条，不影响外部引文。回答下方有复制、引用、追问和重新生成。追问不自动调用；重生成用原问题和资料、当前设置重新调用，失败/停止恢复原回答。失败重试不自动发生。

上翻历史时暂停自动跟随，点向下箭头回到最新回答。在设置调整主题和12/13/14/16px字号，默认跟随系统和13px。

## 快捷键和系统限制

Ctrl+Alt+A读屏/取消，Ctrl+Alt+S展开/收起。两组可独立录入、修改和清除；录入时暂停全局触发，Esc取消。组合被系统占用时保留原值。

Windows不使用Mac的辅助功能/屏幕授权面板。部分阅读软件不提供选区，受保护或更高权限窗口可能不可读；这些限制不影响文字对话。不要为应用关闭系统保护或要求管理员常驻。

## 保存和更新

Key 在当前用户凭据管理器，目标名 `com.decous.anysidebar.windows.deepseek`。对话、截图及布局在 `%LOCALAPPDATA%\AnySidebarForWindows`。SQLite提供事务及备份；若报告损坏，请保留目录和备份，不要用重装清空资料来尝试修复。

正常退出后替换完整应用包或运行包内安装脚本，数据保留。确认删除任务或全部会话会删除相应记录和独占截图，但保留Key和偏好；清Key保留对话。
