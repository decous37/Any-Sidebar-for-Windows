## 12 项原生桌面检查

1. WebView2 加载真实前端，桥接完成启动。
2. 点击页面“收起浮窗”，原生窗口确实隐藏。
3. 隐藏桌面入口后，托盘动作可恢复入口。
4. 默认全局快捷键成功注册；实际按键可展开、收起侧栏。
5. WebView2 获得焦点时，快捷键录入捕获组合键，Esc 可取消。
6. Windows 凭据写入、读取、删除正常；页面视图不包含凭据值。
7. 独立公开阅读样例进程的选文自动进入最新引用。
8. 再次按读屏快捷键取消区域覆盖层，不产生附件。
9. 窗口选择后取得真实 PNG，保存到原会话并展开面板。
10. 可编辑样例控件的选区不会被自动采集。
11. 退出准备握手保存页面最后输入的草稿。
12. 发布的 x64 EXE 显示完整侧栏；第二实例退出并交还控制；右键入口退出后进程正常结束。

凭据和阅读资料均为公开测试占位内容，只存在于一次性托管环境。第 12 项运行实际发布 EXE，其余项目在引用生产模块的系统检查程序中执行；没有向正式应用加入测试端点。

仓库保留[原生结果 JSON](validation/windows-desktop-0.1.0.json)和[公开样例截图](validation/public-fixture-capture.png)。工作流的 `windows-evidence` 还提供布局截图，保留期 7 天；长期可核对执行日志和测试源码。

## 发布包

版本 0.1.0，x64 和 ARM64 ZIP，自包含 .NET 10，需要系统提供 WebView2。源码来自验证提交；最终交付仅补充文档和验收证据，生产代码不变。

两个 ZIP 均检查了应用、.NET 运行时及 SQLite 原生库的 PE 架构，分别为 x64 `0x8664`、ARM64 `0xaa64`；已核对前端引用当前快捷键录入代码。包内含资源、安装脚本及第三方许可，无 Key、会话数据库、私钥或调试符号。下载页同时提供 `SHA256SUMS.txt`。

软件尚未代码签名；实际 ARM64 运行、Windows 10/11 消费版设备、多屏缩放、受保护窗口和各种 PDF 阅读器仍需后续实测。本轮未进行真实 DeepSeek 调用，因此模型图像理解和回答质量保持未验证。

## 验证中修复的问题

早期执行暴露了 SQLite 文件锁、隐藏窗口等待 WebView2 初始化、桌面入口恢复和页面快捷键录入问题，均已修复并在最终执行复测。另补充了发布 EXE 启动、单实例和正常退出检查，避免只测检查程序而遗漏正式入口。

用户授权整体适配、自行补齐四份文档并开发，按“先完成初版、再集中测试”推进。开发中分阶段上传，未改动 Mac 或 Chrome 的安装与数据。
