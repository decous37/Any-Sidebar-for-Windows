# Any Sidebar for Windows · 需求规格

版本：1.0
日期：2026-11-09
状态：用户明确授权沿用 Mac 产品规则，自行完成四份 Windows 文档后直接开发；不再逐节确认。测试按用户要求集中在初版实现完成后执行。

## 背景与目标

开发可独立构建、运行和分发的 Windows AI 侧边栏，与 Mac 仓库 `ef8929f` 的实际界面和产品规则一致。复用 React 前端，重写 Windows 系统窗口、选文、截图、凭据和快捷键。不能把 Mac 尚未验证的能力写成 Windows 已通过。

### 功能需求

- **F1 侧边栏入口**：可拖动桌面入口、系统托盘、展开/收起浮动面板。面板靠近入口且限制在可用屏幕内，系统材质可用时轻微透明，不支持时同色实色回退、文字清晰。左上角收起、会话抽屉、设置左侧返回。右键提供展开/收起、区域读屏、窗口读屏、设置、隐藏入口、退出。收起继续生成，退出停止请求并保存已接收内容。
- **F2 会话**：首次空会话；新建、重命名、切换和确认后删除。独立保存草稿、引用、图片、回答。切文件不换会话；请求和截图冻结原会话归属。后台会话生成不串入当前会话。
- **F3 外部选文**：首次同意后开启自动采集；读取前台阅读区域的选中文字，不采集密码、可编辑输入或本应用控件，不监视剪贴板，不模拟复制。采集不抢焦点、不展开、不上传；不支持的应用可使用截图。默认仅最新，可切换累积；明确在来源取消选区时移除对应最新引用，进入助手输入框仍保留。迟到清除不删除新引用。
- **F4 主动读屏**：默认框选，支持窗口模式。Esc 或再次读屏取消当前操作；不生成附件、不清理草稿。截图时隐藏本应用和覆盖层，保持像素坐标与缩放正确，来源可靠时记录应用和窗口标题。成功进入启动动作所属会话并展开面板。最多新增9张、每张10 MiB、历史合计16个图像块、完整请求体24 MiB，保留原图，不静默裁剪。
- **F5 快捷键**：默认 Ctrl+Alt+A 读屏/取消、Ctrl+Alt+S 展开/收起。两组分别录入、修改、清除、保存及重启恢复；录入期间两项暂停，取消后恢复。系统注册冲突不能伪报成功，保留旧组合，不记录全局按键文本。
- **F6 对话与模型**：用户自备 Key，直接连接 DeepSeek 官方 API；文字、图文和仅图片均可发送。模型及思考强度在输入区切换，按能力配置验证图片兼容性。流式回答、折叠思考、停止、失败手动重试、最后完成回答重新生成。重试/重新生成冻结原资料、应用当前模型设置；重新生成失败或停止恢复原回答。缺 Key 先提示，确认后定位设置，草稿保留且保存 Key 不自动发送。
- **F7 引用与回答操作**：外部引用与独立单条 AI 引用并存。AI 正文/代码/表格可划选，不采集思考及控件；切输入框保留，明确在回答区域取消选区移除。复制、引用、追问、重新生成。引用单行省略、可看全文。发送冻结资料，只清理实际提交部分，准备期间新增内容保留。
- **F8 阅读理解**：问题决定任务，资料和历史提供依据；不声称读取全文或系统文件。必要时解释代码作用与资料关系，区分原文、知识与推测；资料及旧回答中的指令不能改变系统角色。图像不清晰时明确说明，不编造。仅一个模型请求，无额外自动审查。
- **F9 偏好和隐私**：跟随系统主题、13px，提供亮暗和12/13/14/16px。默认 Flash、思考高、最新引用；自动划词默认关闭。Key 用当前用户系统凭据保护，普通界面仅知配置状态；不进入会话或日志。数据本机保存，无账号、云同步、收费、遥测或中转。清空会话保留 Key 和偏好，清除 Key 保留会话。
- **F10 错误及恢复**：Enter发送、Shift+Enter换行、输入法组合不误发送；推荐项直接发送；上翻暂停跟随、一键到底恢复。退出/崩溃后已存输出可恢复，未完成请求标记中断，不自动再计费。存储失败不伪报保存；凭据读取失败不误报未填写。受保护/高权限窗口和不支持选区给出替代方式，不默认要求管理员权限。
- **F11 工程交付**：独立公开仓库 Any-Sidebar-for-Windows，阶段提交、持续上传。中文 README、使用/开发/隐私文档、MIT许可及第三方声明。独立构建脚本，生成 Windows x64、arm64 包；未代码签名时如实说明。开发完成后集中进行验证，不反复开虚拟机。

## 非功能需求

- **N1 平台**：面向 Windows 10 22H2+、Windows 11，x64及arm64。常规用户运行，不依赖 Mac 仓库、不启动本地 HTTP 服务。WebView2 缺失提供官方安装路径和明确错误。
- **N2 一致性**：同一会话至多一个活动请求，操作ID去重；模型回答、附件、切换及清理均校验目标和版本。不因刷新重复调用。
- **N3 安全边界**：受校验的本地桥接；阻止远程导航和远程子资源，外链仅允许明确点击HTTP/HTTPS并交系统浏览器；附件访问按有效ID和归属查找，不开放任意路径。系统凭据和完整文件路径不回传页面。
- **N4 资源**：UI不执行网络等待或无界辅助功能遍历；选文读取有界、节流并在后台线程；图片、文本、上下文和请求体发送前预算检查。输出批量保存，终态保存余量；取消和退出释放覆盖层、监听、句柄与热键。
- **N5 布局**：亮暗、320/480/600px、四档字号；无整体横滚，代码表格可局部滚动。多屏和DPI对应物理截图/逻辑窗口坐标，不将两者混用。
- **N6 验证诚实**：初版完成后一次集中执行类型、lint、界面与领域回归、原生编译、打包和系统检查。真实 Windows 与模拟检查分开；没有实测证据不标记通过。默认不调用付费API。

## 不做的事

不读文档全文、不持续录屏、不全局录键或监视剪贴板、不自动操作原软件、不OCR替代图像模型、不收费、不加用户账号/云同步/自动更新服务、不承诺所有阅读器兼容、不借移植改动 Mac 的行为。

## 验收标准

- **AC1/F1**：桌面/托盘/热键均能展开收起，靠近入口且不出工作区；收起不停止模拟流，退出正常终止。
- **AC2/F1**：左收起、抽屉、返回、右键七项操作可用；隐藏后托盘恢复。
- **AC3/F2**：两会话草稿、引文、截图和流式输出独立；删除仅清理目标。
- **AC4/F3**：支持选区的阅读软件划词自动入草稿且无焦点抢夺；默认仅最新可切累积；输入/密码/本应用不采集。
- **AC5/F3**：取消源选区移除对应最新引用，进输入框保留，迟到事件不能清除新引文。
- **AC6/F4**：区域和窗口截图进入原会话；Esc/二次快捷键取消不产生附件、不上传。
- **AC7/F4/N5**：混合DPI及多屏检查框选与PNG内容对应，排除本应用，失败草稿不丢。
- **AC8/F4**：9/10张、10MiB边界、16/17历史图块和24MiB边界按规定接受/拒绝，无静默删减。
- **AC9/F5**：两组默认注册成功；修改/清除/重启/冲突/录入取消不误触发且旧绑定恢复。
- **AC10/F6**：文字、图文、仅图片的请求体正确，文字模型遇图片拒绝；新设置立即用于新发送。
- **AC11/F6**：三种发送入口缺Key先提示，定位设置且保留资料，保存后不自动发送。
- **AC12/F6/N2**：流式分块、UTF8/SSE边界、停止、异常、超时、失败重试和重新生成恢复可观测，不自动重试。
- **AC13/F7**：外部及AI引文并存、AI替换与取消正确；引用全文冻结；选择新内容不影响旧请求。
- **AC14/F7**：复制、追问不自动收费，重新生成只请求一次；提交期间新编辑或附件保留。
- **AC15/F8**：上下文顺序与角色边界正确；正文不存在时不声称阅读全文；真实质量与请求结构验证分开记录。
- **AC16/F9**：四档字号、亮暗、模型和引用偏好即时保存并重启恢复；Key不进入数据库、页面视图和包。
- **AC17/F9**：正常重装更新保留本机数据；删除/清空/清Key符合独立边界。
- **AC18/F10**：IME、Enter、推荐项、一键到底、历史浏览和字号变化符合Mac行为。
- **AC19/F10**：异常重启仅恢复已存内容，不自动请求；磁盘/凭据异常有准确提示。
- **AC20/F11**：独立目录干净安装依赖可构建，x64/arm64生成可审计ZIP，源码与中文文档在新仓库可见，无个人数据。
- **AC21/N3**：桥接未知字段、非法ID/路径/来源/URL被拒绝，恶意Markdown不会执行代码或读取文件。
- **AC22/N4**：后台采集有界、取消资源释放、关闭后监听与热键注销；不持续截图。
- **AC23/N5**：亮暗三宽度四字号检查主操作可见；代码和表格不撑破整体布局。
- **AC24/N6**：集中验证记录包含实际命令、结果与环境；实机缺失项如实保留，模拟API不产生费用。
