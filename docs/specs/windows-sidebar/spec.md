## 背景与目标

开发 Any Sidebar 的独立 Windows 桌面版本，产品定位为轻量 AI 侧边栏。以 Mac 仓库 `ef8929f` 的实际界面及行为为对齐基线，同时参考已批准的 Mac 规格和后续用户补充；不把 Mac 尚未实测的行为当作 Windows 已验证能力。

用户通过桌面入口、系统托盘或快捷键展开浮动侧边栏，在原阅读软件旁进行文字与图像对话。沿用白色、轻蓝色、亮暗主题和紧凑 React 前端，包括收起按钮、会话抽屉、外部引用、AI 回答引用、截图、模型与思考菜单、设置及回答操作。

Windows 替换系统相关实现：从支持选区的阅读软件自动采集划词，手动截取区域或窗口，系统凭据保护、全局快捷键、托盘及桌面窗口。会话按任务隔离，本机保存；不读取整个文档、不持续录屏，不引入收费、账号、云同步或项目方 API 中转。

继承 Mac 的当前默认值：仅最新引用、13px、跟随系统主题、Flash 与高思考强度。Windows 快捷键由开发方选择，必须可录入、修改、清除和提示注册冲突，不占用不带修饰键的日常输入。

本次交付独立 `Any-Sidebar-for-Windows` 公开 GitHub 仓库、中文文档、完整实现、构建与打包流程，以及如实区分已验证和未验证的验收记录。开发过程中按完整模块逐步提交上传。先完成可用初版，再集中执行测试和必要的 Windows 验证，不反复启动虚拟机；缺少实机环境不能表述为已经通过真实系统验收。

### 本阶段判断依据

- 原生窗口和采集能力依赖 Windows；React 页面可沿用。
- 同类操作采用相同产品语义，系统授权方式与快捷键按 Windows 习惯适配。
- 划词兼容性取决于阅读软件提供的辅助功能选区，不能承诺所有应用可采集。
- 本机没有 .NET 工具链，也没有当前已确认可用的 Windows 测试会话；后续需补齐构建环境，并集中安排真实运行检查。
