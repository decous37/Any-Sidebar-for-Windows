# 隐私说明

Any Sidebar for Windows 是使用自备 API Key 的本机侧边栏。没有项目方账号、中转服务器、遥测或云同步。

## 采集什么

自动划词默认关闭，确认说明并启用后，尝试取得前台阅读软件的选中文字和可靠来源信息（应用、窗口标题、获取时间）。不扫描文档全文，不采集密码及可编辑输入，不记录键盘文本或剪贴板历史。

截图仅在你点击读屏或使用快捷键时发生。可以选择区域或窗口，取得当前可见图像；不持续录屏，不自动滚动。

## 本机保存

会话、引用、截图、请求资料与偏好位于 `%LOCALAPPDATA%\AnySidebarForWindows`。这些文件没有额外加密，依赖Windows账户和设备保护。API Key 单独存入当前用户Windows凭据管理器，不写入会话、快照、日志或页面返回值。

临时网络请求体包含发送的图像和文本，只用于当前原生HTTPS请求，不作为日志保存。公开安装包不包含个人数据或Key。

## 发送给谁

只有发送问题、失败手动重试或重新生成时，相关问题、选文、图片及必要历史直接提交给DeepSeek官方API，并产生你的账户用量。仅打开侧栏、划词或截图不调用模型。DeepSeek对API资料的处理按其官方政策执行。

WebView2为微软提供的系统运行时，其自身更新与诊断受微软政策及系统设置约束；本项目不额外收集使用统计。

## 如何控制

可以关闭自动划词、取消截图、删除附件或会话、清空记录、单独清除Key或退出。收起面板继续已发请求，退出停止新增采集和本机请求接收；服务端已接收的请求不能通过本机删除撤回。

更新应用保留外部数据。清空会话保留Key和偏好，清除Key保留对话。请不要在公开Issue上传私人文档、完整截图或凭据。
