# 0.1.1 修复验证

日期：2026-11-09。截图显示和记事本文档划词两项修复已通过真实 Windows 检查。未使用真实 Key、私人文档或付费模型，也未启动本机虚拟机。

## 原因与改动

**截图显示损坏图标**：网页采用 WebView2 虚拟主机映射，而图片同时走相同域名的动态请求处理。映射资源不会触发该处理，导致文件虽然保存成功，页面仍拿不到图片。这与[微软对映射和请求事件的说明](https://github.com/MicrosoftDocs/edge-developer/blob/main/microsoft-edge/webview2/how-to/webresourcerequested.md)一致。

动态截图改用独立、未映射的本机来源 `https://anysidebar-assets.local`。UUID、附件存活状态、文件校验和路径限制保持；CSP 与前端视图只放行该图片来源，不开放远程图片或任意文件。网址仅由应用内部响应，不是上传服务。

**文本文档选文无法加入上下文**：旧规则排除了所有可编辑输入，系统记事本的文档编辑面板也被排除。现在同时核对 notepad 进程、Notepad 顶层窗口及文档编辑控件类别，再读取已选文字。普通表单、查找框、密码和本应用控件继续排除；不模拟复制，不读取全文或剪贴板。

自动划词仍需先确认采集说明并开启“自动接收划词”，本次不擅自更改用户的开关。

## 范围与交付

版本 0.1.1 的 x64、ARM64 包保留应用数据目录、数据库结构和系统凭据目标。附件 URL 每次从状态生成，未写入旧数据库，因此没有新增迁移或清理动作；仍需后续在已有 0.1.0 用户数据库上实际更新、重开验证。

本轮实测的是托管环境中的系统记事本，不代表所有第三方编辑器和 Windows 11 新记事本版本均已覆盖。截至 2026-11-09，ARM64 实际运行、消费版 Windows 多屏/DPI 和真实模型效果未验证；2026-11-10 的 ARM 虚拟机补充检查见下节。原版完整验证范围见[0.1.0 验收报告](validation-report.md)。
